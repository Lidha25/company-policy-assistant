Rules-based search is fast and uses no AI tokens because it returns matching policy text, but keyword matching can select an irrelevant policy or miss a question phrased differently. The full-database Gemini approach can consider every policy at once, but it uses more tokens and can still make claims the database does not support. Vector search uses an embedding model to retrieve five semantically related policies before answering, which can reduce the text sent to Gemini; however, it can miss an important condition if that policy is not among the retrieved five.
