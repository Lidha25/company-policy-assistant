Rules-based search matches keywords and returns an exact policy sentence, so it uses no LLM tokens and cannot invent new wording; however, it can still return an irrelevant rule or fail to answer a paraphrased question. The LLM without a vector index receives all 98 CSV entries with each question, while the vector approach first retrieves five entries by embedding similarity and supplies only those entries to the same model. For this small database of 98 short policies, my provisional preference is the LLM without a vector index because it can read every entry and avoids losing a relevant policy during retrieval.
